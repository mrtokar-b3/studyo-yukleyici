Privacy Policy

Studyo Yukleyici. Last updated: November 18, 2026.

What this app is

Studyo Yukleyici is a private desktop tool used only by its owner to manage the owner's own YouTube channels. It is not offered to the public.

YouTube API Services

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data it accesses

  • Basic information about the signed-in YouTube channel (name, ID, subscriber and video counts).
  • Details of the channel's own videos (title, description, tags, privacy status, scheduled time) so it can upload, schedule and check them.
  • The channel's YouTube Analytics reports (views, watch time, subscribers, traffic sources) for the owner's weekly report.

It uploads only video files, thumbnails and captions that the owner prepared on their own computer.

How data is stored and shared

Access tokens are stored only on the owner's computer. Data read from YouTube is used only to show the owner reports about their own channels. Nothing is sold, shared with third parties, used for advertising, or sent to any server other than Google's. This website sets no cookies and collects no data.

How to revoke access

Access can be removed at any time from the Google account's third-party connections page or the security settings. Removing access deletes the app's ability to read or change the channel.
